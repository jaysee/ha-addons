# Home Assistant Add-ons by jaysee

A collection of custom Home Assistant add-ons.

## Installation

1. Go to **Settings → Add-ons → Add-on Store**
2. Click **⋮** (top right) → **Repositories**
3. Add:
   ```
   https://github.com/jaysee/ha-addons
   ```
4. The add-ons will appear under **Home Assistant Add-ons by jaysee**

## Add-ons

| Add-on | Version | Description |
|--------|---------|-------------|
| [GPS Tracker](gps_tracker/) | 0.1.9 | Expose a USB GPS receiver as a `device_tracker` entity with full NMEA telemetry |
